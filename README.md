# Meeting Landing

Close a meeting with a named owner and actual due date for each decision.

Set up to six decisions and owners as comma-separated values in device settings. Turn to a decision and click to edit. Turn to choose an owner, click to move to due days, then turn and click to confirm. Start returns to the list. In list mode, hold the wheel to mark the selected action done or reopen it.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
